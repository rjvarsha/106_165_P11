### Project Description

THE CIPHER is a Sherlock Holmes-inspired, MERN-stack web application designed to modernise food safety inspections through intelligent validation, automated violation classification, and efficient investigation management.

The platform integrates concepts from **Automata Theory and Computer Networks**, implementing Deterministic Finite Automata (DFA) and Regular Expressions to validate inspector IDs and violation codes. It classifies inspection reports into five categories — Critical, Major, Minor, Advisory, and Passed — and uses priority-based scheduling to streamline case processing.

Featuring an interactive intelligence map covering all 31 districts of Karnataka, THE CIPHER enables geographical monitoring, operational zone management, and intelligent officer allocation based on jurisdiction, availability, and workload.

Additional features include citizen complaint registration, complaint cluster detection, digital evidence management, investigation tracking, officer workload monitoring, analytics dashboards, and smart inspection route optimisation.

Built using the **MongoDB, Express.js, React.js, and Node.js (MERN) stack**, THE CIPHER brings food safety reporting, investigation, and field operations together in one unified platform.
